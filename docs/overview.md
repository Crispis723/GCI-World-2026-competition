# Documentación del proyecto

Este repositorio contiene recursos para participar en la competencia GCI World 2026.

Contenido:

- `src/` — Código fuente organizado para facilitar pruebas y despliegue.
- `notebooks/` — Notebooks con experimentos y análisis exploratorio.
- `data/` — Carpeta para datasets (no incluida por defecto).
- `tests/` — Pruebas automatizadas.

Objetivo:

Proveer una estructura mínima reproducible y fácil de usar para desarrollar soluciones y compartir experimentos.
