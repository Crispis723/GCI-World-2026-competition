# GCI-World-2026-competition

Proyecto de ejemplo para la competencia GCI World 2026.

Estructura sugerida del repositorio:

- `src/` – Código fuente del proyecto.
- `notebooks/` – Notebooks exploratorios y experimentos (incluye `baseline.ipynb`).
- `data/` – Datos sin procesar y subcarpetas para datos procesados.
- `docs/` – Documentación del proyecto.
- `tests/` – Pruebas unitarias y de integración.
- `.gitignore` – Archivos y carpetas a ignorar por Git.
- `requirements.txt` – Dependencias Python.

Cómo usar:

1. Crear un entorno virtual: `python -m venv .venv`
2. Activarlo: `source .venv/bin/activate`
3. Instalar dependencias: `pip install -r requirements.txt`
4. Ejecutar el script principal: `python -m src.run`

Si deseas que mueva archivos existentes a la nueva estructura, indícamelo y lo hago.
